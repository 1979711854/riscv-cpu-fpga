## 0. 题目定位与分值敏感点

用 Verilog/SystemVerilog，在紫光同创 FPGA 板上实现 **RV32I CPU（≥3 级流水线，含数据冒险与分支处理）**，集成 UART/GPIO，跑 `riscv32-unknown-elf-gcc` 编译的 C 程序与 **CoreMark v1.0**，并给出应用场景 + 性能分析文档。

评分最看重的五件事（按权重感排序）：
1. **执行效率 CoreMark/MHz** —— 流水线越顺、停顿越少越高；
2. **时钟频率 Fmax** —— 满足时序约束下能跑多高；
3. **资源效率 CoreMark/LUTs** —— 用最少逻辑拿最高分；
4. **应用场景演示** —— CPU 要"有用"：游戏机/工控/逻辑分析仪/图像加速等任选其一；
5. **代码规范 + 分析报告** —— 模块化、时序约束、注释、**用 ILA 抓 CoreMark 关键段波形分析流水线效率**。

高阶加分项（可选，投入巨大，量力而行）：
- 2 路组相联 指令+数据 Cache，优化总线突发传输；
- BTB 动态分支预测 + 完整 RISC-V 异常/中断；
- 边缘 AI 加速：移植 YOLO/轻量 LLM + 传感器/显示。

## 1. 总体策略（保底优先）

**顺序：先让 CPU "对且能跑 C/CoreMark"，再谈性能与高阶项。**
未达成 P0 前不碰流水线优化细节；未跑通 CoreMark 前不碰 Cache/BTB。

- P0 = 门槛：正确 RV32I + 流水线 + 外设 + 能跑 gcc C 程序 —— **拿基础分**
- P1 = 提分：CoreMark 达标(≥10s) + Fmax 优化 + ILA 报告 —— **拿性能/文档分**
- P2/P3 = 拉分：BTB+中断 → Cache → （AI 单独评估）
