# 比赛任务计划 — RISCV 处理器设计（紫光同创）

> 依据《全国大学生嵌入式芯片与系统设计竞赛 2026 选题指南（紫光同创）》RISC-V 处理器设计整理。
> 状态更新日期：2026-09-08

## 0. 题目定位与分值敏感点

用 Verilog/SystemVerilog，在紫光同创 FPGA 板上实现 **RV32I CPU（≥3 级流水线，含数据冒险与分支处理）**，集成 UART/GPIO，跑 `riscv32-unknown-elf-gcc` 编译的 C 程序与 **CoreMark v1.0**，并给出应用场景 + 性能分析文档。

评分最看重的五件事（按权重感排序）：
1. **执行效率 CoreMark/MHz** —— 流水线越顺、停顿越少越高；
2. **时钟频率 Fmax** —— 满足时序约束下能跑多高；
3. **资源效率 CoreMark/LUTs** —— 用最少逻辑拿最高分；
4. **应用场景演示** —— CPU 要"有用"：游戏机/工控/逻辑分析仪/图像加速等任选其一；
5. **代码规范 + 分析报告** —— 模块化、时序约束、注释、**用 ILA 抓 CoreMark 关键段波形分析流水线效率**。

高阶加分项（可选，投入巨大，量力而行）：
- 2 路组相联 指令+数据 Cache，优化总线突发传输；
- BTB 动态分支预测 + 完整 RISC-V 异常/中断；
- 边缘 AI 加速：移植 YOLO/轻量 LLM + 传感器/显示。

## 1. 总体策略（保底优先）

**顺序：先让 CPU "对且能跑 C/CoreMark"，再谈性能与高阶项。**
未达成 P0 前不碰流水线优化细节；未跑通 CoreMark 前不碰 Cache/BTB。

- P0 = 门槛：正确 RV32I + 流水线 + 外设 + 能跑 gcc C 程序 —— **拿基础分**
- P1 = 提分：CoreMark 达标(≥10s) + Fmax 优化 + ILA 报告 —— **拿性能/文档分**
- P2/P3 = 拉分：BTB+中断 → Cache → （AI 单独评估）

## 2. 分阶段任务清单

### P0-0 环境与最小工程（0.5~1 天）
- [ ] 确认板卡型号与 FPGA 芯片（紫光同创型号）、拿到官方引脚约束与板卡手册
- [ ] PDS 建空工程；写分频+LED，综合→实现→生成 bit→下载
- [ ] **验收：LED 可控亮灭/流水灯**；PDS 工程目录、git 忽略规则理顺

### P0-1 RV32I 内核（先仿真后综合）（核心，占大头）
- [ ] 搭 PC / 指令 BRAM / 寄存器堆(32×32) / ALU / 控制单元 / 立即数扩展
- [ ] 实现 RV32I 全指令（含 `lui auipc jal jalr beq bne blt bge bltu bgeu lb lh lw lbu lhu sb sh sw addi slti… 与 加减逻辑/移位/比较/CSR 留到中断阶段`）
- [ ] 单周期版先仿真跑通（打基础，最终版本是流水线）
- [ ] 数据通路先写、控制信号表后填；用官方 `riscv-tests` 的 rv32ui 子集做回归
- [ ] **验收：仿真跑完小程序终值正确**
- [ ] 改造为 **5 级流水线 IF/ID/EX/MEM/WB**：数据前递 + 载入-使用停顿 + 分支/跳转处理
- [ ] 写清冒险处理方案（转发路径表、stall/flush 时机）——**报告要讲这部分**
- [ ] **验收：带流水线冒险的测试程序全部通过**

### P0-2 最小 SoC + 外设（跑 C 程序的前提）
- [ ] 定义存储器映射（指令/数据区 + 外设区）
- [ ] 数据 BRAM + 简单地址译码总线（暂不用 AXI）
- [ ] GPIO、UART 控制器（含波特率分频、发送/接收 FIFO）
- [ ] 顶层：PLL 时钟、复位、程序上电自动加载
- [ ] 安装 `riscv32-unknown-elf-gcc`；写链接脚本(内存布局)+ `objcopy` 转 hex 的流程
- [ ] **验收：CPU 执行 C 代码，经 UART 打印 printf 输出到 PC 串口**

### P1 CoreMark + 性能调优（提分主战场）
- [ ] 移植 CoreMark v1.0；确定迭代次数使运行 ≥10s
- [ ] 搭计时：用片上计数器/示波器统计迭代总周期，算 CoreMark/MHz
- [ ] 关掉不必要停顿；降低分支代价（如简单静态预测/延迟槽分析）
- [ ] 时序优化：关键路径在 EX 的 ALU/前递，调整以提升 Fmax
- [ ] 资源优化：控制逻辑化简，统计 LUT 占用
- [ ] **验收：CoreMark/MHz 与 Fmax 记录在案**
- [ ] 用 PDS 的 ILA(集成逻辑分析仪) 抓 CoreMark 关键段，分析各流水段活跃/停顿占比，写进报告

### P2 高阶-控制（若时间够，性价比高）
- [ ] 动态分支预测 BTB + 预测失败恢复
- [ ] CSR 组、异常(ecall/非法指令/取指/访存错误)、中断入口 mtvec/mcause/mepc、mret、外部中断(按键/定时器)

### P3 高阶-存储（工程量大，谨慎排期）
- [ ] 2 路组相联 I/D Cache + 写策略；总线突发传输（评估是否引入 AXI-Lite）

### P4 应用场景 + 文档（贯穿全程，别最后堆）
- [ ] 从"逻辑分析仪/采集卡/游戏机/工控"挑一个能自洽演示的场景，把 GPIO/UART 用起来
- [ ] 架构文档 doc/spec.md（ISA 子集、流水线级数与冒险表、存储器映射、外设寄存器）
- [ ] 代码注释规范、模块化分层自检
- [ ] 报告：性能公式、ILA 波形分析、与单周期基线对比
- [ ] （可选、单独评估投入）AI：评估时间后再决定是否接入
