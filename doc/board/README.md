### [!] CRC 怎么比才对：**别拿 `crcfinal` 当判据**

| CRC | 随 ITER 变吗 | 能不能用来比对 |
|---|---|---|
| `seedcrc` / `crclist` / `crcmatrix` / `crcstate` | **不变** | [OK] **这才是判据**，跨 ITER、跨时钟都必须逐位相同 |
| `crcfinal` | **变** | [X] 不能比 |

**依据（读 CoreMark 源码确认，`third_party/coremark/core_main.c` 的 `iterate()`）：**

```c
res->crc = 0;
for (i = 0; i < iterations; i++) {
    crc      = core_bench_list(res, 1);
    res->crc = crcu16(crc, res->crc);      // ← crcfinal 是【跨迭代累加】的
    crc      = core_bench_list(res, -1);
    res->crc = crcu16(crc, res->crc);
    if (i == 0) res->crclist = res->crc;   // ← 子 CRC 只在第 0 轮快照一次
}
```

`[0]crcfinal` 打印的是 `results[0].crc`，即上面那个**累加器** —— 它必然随 ITER 变：

| 运行 | ITER | crcfinal |
|---|---|---|
| 仿真 | 1 | `0xe714` |
| 27 MHz 板 | 820 | `0xbd59` |

## 硬件现状说明（写报告时用得着）

* **手册是 0 起编号，板上丝印是 1 起编号**：手册 `KEY0..KEY4` = 丝印 `KEY1..KEY5`。
* **LED 丝印相对开关是错位的**，这是板卡硬件现状，不是映射错误：

  | 手册 | FPGA 管脚 | 板上丝印 | 位置 |
  |---|---|---|---|
  | LED0 | A20 | D17 | SW3 下面 |
  | LED1 | C18 | D18 | SW5 下面 |
  | LED2 | C19 | D19 | SW4 下面 |
  | LED3 | E18 | D13 | SW6 下面 |
  | LED4 | A17 | D14 | SW7 下面 |
  | LED5 | A18 | D15 | — |
  | LED6 | C17 | D16 | — |
  | LED7 | B17 | D12 | — |

  所以演示程序（`LED = KEY`）按某个开关时，亮的是**该开关隔壁**的灯，
  而非正下方那个 —— 串口日志里 `KEY=0x08 LED=0x08` 证明写入字节与读到字节
  完全一致，映射本身正确。

### 收益分解

```
313,886（-O2 基线）→ 282,777（阶段0 -O3，−9.91%）→ 262,018（阶段1，−7.34%）
合计 −16.5%   →   得分 270.82 → 324.5（+19.8%）
乘法闭合：1.1100 × 1.0792 = 1.1979
```
**板上与仿真一致**（324.5 vs 仿真口径 324.42，差 +0.03%）。

> [!] **"板/仿真差 48 拍"已查明：是 ITER 效应，不是仿真模型误差。**
> 三个点单调递减并收敛：
>
> | 测量 | 拍/迭代 |
> |---|---|
> | 仿真 ITER=1 | 262,018.0 |
> | 仿真 ITER=20 | **261,983.3**（−34.8）|
> | **板上 ITER=3796** | **261,969.8**（−48.2）|
>
> 原因：`-O3 -funroll-all-loops` 下 `for (i<ITERATIONS)` 有约 **48 拍的一次性
> 循环开销**。ITER=1 时它没被摊掉，全算进"每迭代"；ITER 越大越接近真实
> `iterate()` 成本。**所以板上与仿真是一致的。**
>
> **[重点] 教训：`-O3` 之后，"每迭代周期数"是与 ITER 相关的。**
> 拿它算 ITER（`ITER = 时钟×10 ÷ 每迭代`）时要用**大 ITER 下的值**；
> 用 ITER=1 的信会偏 0.018%（本例无实质影响：两种算法都取 3796）。
> 更稳的做法：**用 `+PROF` 的 `region cycles`**（它框的是 `start_time→stop_time`
> 之间的纯 `iterate()`，不含外层循环开销）—— 判据仍是"必须等于 `Total ticks`"。
