# RV32I 指令集参考手册

> 本文档适用于单周期 RISC-V CPU 设计与开发参考，包含主控制单元译码表、ALU 精细译码表、六种指令格式、完整指令分类速查表及立即数拼接方式。


## 一、主控制单元 (`main_ctrl`) 译码表

按 `opcode` 索引，`main_ctrl` 需要输出的控制信号：

| opcode | 指令类型 | RegWrite | ALUSrc | MemRead | MemWrite | Branch | Jump | ALUOp |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| `0110111` | LUI | 1 | 0 | 0 | 0 | 0 | 0 | `ADD` |
| `0010111` | AUIPC | 1 | 0 | 0 | 0 | 0 | 0 | `ADD` |
| `1101111` | JAL | 1 | 0 | 0 | 0 | 0 | 1 | `ADD` |
| `1100111` | JALR | 1 | 1 | 0 | 0 | 0 | 1 | `ADD` |
| `1100011` | 分支 | 0 | 0 | 0 | 0 | 1 | 0 | `BRANCH` |
| `0000011` | 加载 | 1 | 1 | 1 | 0 | 0 | 0 | `ADD` |
| `0100011` | 存储 | 0 | 1 | 0 | 1 | 0 | 0 | `ADD` |
| `0010011` | OP-IMM | 1 | 1 | 0 | 0 | 0 | 0 | `RTYPE` |
| `0110011` | OP | 1 | 0 | 0 | 0 | 0 | 0 | `RTYPE` |

> **控制信号说明**：
> - `RegWrite`：是否写入寄存器堆
> - `ALUSrc`：ALU 的 b 端口选择（0=rs2，1=立即数）
> - `MemRead` / `MemWrite`：数据存储器读写使能
> - `Branch`：分支指令（PC 是否跳转取决于分支单元计算结果）
> - `Jump`：无条件跳转（jal / jalr）
> - `ALUOp`：2-bit 粗粒度控制，输入给 `alu_ctrl` 精细译码


## 二、ALU 精细译码表（`alu_ctrl` 模块用）

`alu_ctrl` 接收 `ALUOp`、`funct3`、`opcode5`、`funct7b5`，输出 4-bit `alu_ctrl`：

| ALUOp | funct3 | opcode5 | funct7b5 | alu_ctrl | 对应指令 |
| :---: | :---: | :---: | :---: | :--- | :--- |
| `00` | — | — | — | `ALU_ADD` | lw / sw / lui / auipc / jal / jalr / addi |
| `01` | — | — | — | `ALU_SUB` | beq / bne / blt / bge / bltu / bgeu |
| `10` | `000` | 1 | 0 | `ALU_ADD` | add |
| `10` | `000` | 1 | 1 | `ALU_SUB` | sub |
| `10` | `000` | 0 | — | `ALU_ADD` | addi |
| `10` | `001` | — | — | `ALU_SLL` | sll / slli |
| `10` | `010` | — | — | `ALU_SLT` | slt / slti |
| `10` | `011` | — | — | `ALU_SLTU` | sltu / sltiu |
| `10` | `100` | — | — | `ALU_XOR` | xor / xori |
| `10` | `101` | — | 0 | `ALU_SRL` | srl / srli |
| `10` | `101` | — | 1 | `ALU_SRA` | sra / srai |
| `10` | `110` | — | — | `ALU_OR` | or / ori |
| `10` | `111` | — | — | `ALU_AND` | and / andi |

> **字段说明**：
> - `opcode5` = `inst[5]`，用于区分 R 型和 I 型（OP=1，OP_IMM=0）
> - `funct7b5` = `inst[30]`，用于区分 `add`/`sub` 和 `srl`/`sra`

## 五、立即数拼接方式

不同指令格式的立即数拼接方式不同：

| 格式 | 指令类型 | 拼接方式 |
| :--- | :--- | :--- |
| **I 型** | addi / andi / ... / lw / jalr | `{ {20{imm[11]}}, imm[11:0] }`（符号扩展） |
| **S 型** | sw / sh / sb | `{ {20{imm[11]}}, imm[11:5], imm[4:0] }`（符号扩展） |
| **B 型** | beq / bne / ... | `{ {19{imm[12]}}, imm[12], imm[10:5], imm[4:1], 1'b0 }`（符号扩展 + 末尾 0） |
| **U 型** | lui / auipc | `{ imm[31:12], 12'b0 }`（左移 12 位，低 12 位补 0） |
| **J 型** | jal | `{ {11{imm[20]}}, imm[20], imm[10:1], imm[11], imm[19:12], 1'b0 }`（符号扩展 + 末尾 0） |
