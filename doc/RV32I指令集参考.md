# RV32I 指令集参考手册

> 本文档适用于单周期 RISC-V CPU 设计与开发参考，包含主控制单元译码表、ALU 精细译码表、六种指令格式、完整指令分类速查表及立即数拼接方式。


## 一、主控制单元 (`main_ctrl`) 译码表

按 `opcode` 索引。信号名与 `rtl/core/defs.v`、`main_ctrl.v` 端口一致：

| 信号 | 含义 |
| :--- | :--- |
| `reg_write` | 是否写寄存器堆 |
| `mem_write` / `mem_read` | 数据存储器写/读使能 |
| `mem_to_reg` | 回写源：0=ALU 结果，1=存储器读数据 |
| `alu_src` | ALU 的 B 源：0=rs2，1=立即数 |
| `alu_src_a` | ALU 的 A 源：`ASRC_RS1`(默认) / `ASRC_ZERO`(LUI) / `ASRC_PC`(AUIPC) |
| `branch` / `jal` / `jalr` | 跳转类别标志 |
| `alu_op` | 2-bit 粗控制，取值 `ALU_OP_ADD / ALU_OP_SUB / ALU_OP_ALU` |

| opcode | 指令 | reg_write | mem_write | mem_read | mem_to_reg | alu_src | alu_src_a | branch | jal | jalr | alu_op |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| `0110011` | R 型运算 add/sub/… | 1 | 0 | 0 | 0 | 0 | RS1 | 0 | 0 | 0 | ALU_OP_ALU |
| `0010011` | I 型运算 addi/slti/… | 1 | 0 | 0 | 0 | 1 | RS1 | 0 | 0 | 0 | ALU_OP_ALU |
| `0000011` | 加载 lw（先字） | 1 | 0 | 1 | 1 | 1 | RS1 | 0 | 0 | 0 | ALU_OP_ADD |
| `0100011` | 存储 sw（先字） | 0 | 1 | 0 | 0 | 1 | RS1 | 0 | 0 | 0 | ALU_OP_ADD |
| `0110111` | LUI | 1 | 0 | 0 | 0 | 1 | ZERO | 0 | 0 | 0 | ALU_OP_ADD |
| `0010111` | AUIPC | 1 | 0 | 0 | 0 | 1 | PC | 0 | 0 | 0 | ALU_OP_ADD |
| `1101111` | JAL | 1 | 0 | 0 | — | — | — | 0 | 1 | 0 | — |
| `1100111` | JALR | 1 | 0 | 0 | — | — | — | 0 | 0 | 1 | — |
| `1100011` | 分支 beq/bne/… | 0 | 0 | 0 | 0 | — | RS1 | 1 | 0 | 0 | — |

> **注**：
> - `—` = don't care。写 main_ctrl 时为**避免组合逻辑锁存**，所有输出每行都要赋值；don't care 建议统一填 `0` / `ASRC_RS1` / `ALU_OP_ADD`。
> - JAL/JALR：`rd` 写回 `pc+4`，跳转目标由**顶层专用加法器**计算（`pc+imm`；`rs1+imm` 且最低位清 0），ALU 不参与，故 `mem_to_reg/alu_src/alu_src_a/alu_op` 均可不关心。
> - 分支条件由 **branch_unit** 独立判定（beq/bne/blt/bge/bltu/bgeu 全覆盖），ALU 不参与比较；目标 `pc+imm` 由顶层加法器计算。`next_pc` 优先级：jalr > jal > 分支(branch & branch_taken) > pc+4。
> - 加载/存储本阶段只做 `lw/sw` 字访问；`lb/lbu/lh/lhu/sb/sh` 及其符号扩展是后续扩展点。


## 二、ALU 精细译码表（`alu_ctrl` 模块用）

`alu_ctrl` 接收 `alu_op`(来自 main_ctrl)、`funct3=inst[14:12]`、`opcode5=inst[5]`、`funct7b5=inst[30]`，输出 4-bit `alu_ctrl`（编码见 defs.v `ALU_*`）。
`alu_op` 取值：`00`=`ALU_OP_ADD`，`01`=`ALU_OP_SUB`，`10`=`ALU_OP_ALU`。

| ALUOp | funct3 | opcode5 | funct7b5 | alu_ctrl | 对应指令 |
| :---: | :---: | :---: | :---: | :--- | :--- |
| `00` | — | — | — | `ALU_ADD` | lw / sw / lui / auipc / jal / jalr（addi 走 `10` 译码） |
| `01` | — | — | — | `ALU_SUB` | 预留（本设计分支由 branch_unit 判定，此值一般不驱动） |
| `10` | `000` | 0 | — | `ALU_ADD` | addi |
| `10` | `000` | 1 | 0 | `ALU_ADD` | add |
| `10` | `000` | 1 | 1 | `ALU_SUB` | sub |
| `10` | `001` | — | — | `ALU_SLL` | sll / slli |
| `10` | `010` | — | — | `ALU_SLT` | slt / slti |
| `10` | `011` | — | — | `ALU_SLTU` | sltu / sltiu |
| `10` | `100` | — | — | `ALU_XOR` | xor / xori |
| `10` | `101` | — | 0 | `ALU_SRL` | srl / srli |
| `10` | `101` | — | 1 | `ALU_SRA` | sra / srai |
| `10` | `110` | — | — | `ALU_OR` | or / ori |
| `10` | `111` | — | — | `ALU_AND` | and / andi |

> **字段说明**：
> - `opcode5` = `inst[5]`，用于区分 R 型和 I 型（OP=1，OP_IMM=0）
> - `funct7b5` = `inst[30]`，用于区分 `add`/`sub` 和 `srl`/`sra`；I 型中则用于区分 `srli`/`srai`


## 三、六种指令格式与机器码布局

## 五、立即数拼接方式

不同指令格式的立即数拼接方式不同：

| 格式 | 指令类型 | 拼接方式 |
| :--- | :--- | :--- |
| **I 型** | addi / andi / ... / lw / jalr | `{ {20{imm[11]}}, imm[11:0] }`（符号扩展） |
| **S 型** | sw / sh / sb | `{ {20{imm[11]}}, imm[11:5], imm[4:0] }`（符号扩展） |
| **B 型** | beq / bne / ... | `{ {19{imm[12]}}, imm[12], imm[10:5], imm[4:1], 1'b0 }`（符号扩展 + 末尾 0） |
| **U 型** | lui / auipc | `{ imm[31:12], 12'b0 }`（左移 12 位，低 12 位补 0） |
| **J 型** | jal | `{ {11{imm[20]}}, imm[20], imm[10:1], imm[11], imm[19:12], 1'b0 }`（符号扩展 + 末尾 0） |
