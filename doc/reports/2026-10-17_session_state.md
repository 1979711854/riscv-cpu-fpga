## 3. [重点] 未决大事项：**要不要扩到 128KB**

### 用户为什么要（2026-10-17 明确）

> "我们想让**同一颗 CPU 同时跑 CoreMark 和五子棋**（拍视频演示时要同时展示跑分）。"

### 数字（已核实）

| 项 | 大小 |
|---|---|
| RT-Thread 五子棋（T6）静态 | **54,749 B** |
| CoreMark 镜像（`mem.hex` 17,104 行）| **34,208 B**（8,552 字）|
| **合计** | **88,957 B** |
| 现在可用程序区 `0x1000~0xF000` | **61,440 B** |
| **超出** | **27,517 B** |

⇒ **64KB 装不下，128KB 才装得下（余约 38KB）。**

### 改起来的代价（诚实估计 **1.5~2 天**）

1. **RTL**：地址 14→15 位 —— `core.v`（`imem_addr`/`imem_addr2`/`ld_addr` 三个端口 + 内部切片）、
   `mem_bus.v`、`unified_mem.v`、`sim/mem_model.vh`（`[0:16383]`→`[0:32767]`）
   - [!] **`imem_addr2` 就在关键路径上**（…→`if_addr_d`→`imem_addr`→`imem_addr2`→BRAM 地址口），
     而它现在是 P3.5 专门修过的 14 位（13→14 修"64KB 取指回绕"）
2. **内存映射 + 链接脚本**：`addr_map.vh`/`addr_map.h`、`scripts/rtthread/bsp/link.ld`、
   `scripts/demo/link.ld`（`0xF000` → `0x1F000`）等
3. **所有固件重编 + 全套回归**
4. **重扫 `gplace_seed`**（净表一变，钉住的 seed 5 余量作废 —— A1 实测：LUT +122 就把
   +0.277 打成 −0.156）。A1 文档判"40 跑量级 ≈ 数小时机时"
5. **两颗位流重出 + 板上重验** + 文档五处同步

### [!] 顺序约束（最容易搞错）

```
① 定 128KB 做不做 → ② 做（改 RTL + 重扫 seed + 重出两颗位流）→ ③ 抓 ILA 波形
```

**不能反过来** —— `.fic` 与 `.sbit` 必须来自同一次综合，RTL 一变通道映射全错位。
用户说 ILA 后面在 GUI 抓，**所以 128KB 的决定必须先做**。

### 替代方案（若规则不要求"同一颗位流"）

**视频两段**（先烧跑分档 `c6af65be` 看 391.66 分，再烧演示档 `5909a2d0` 玩五子棋）—— **0 成本**，
而且旁白能强调"**同一份 `rtl/**`、两个固件**"，更贴合"不是两颗 CPU"的答辩口径。
**建议先向用户确认赛题原文对演示的要求，再决定花不花这 2 天。**

> 其他方案都不可行：裸机五子棋+CoreMark 合并 = 25.1+34.2 = 59.3 KB / 61.4 KB，
> 只剩 2 KB 给栈，而 AI 递归要用栈 ⇒ 实际塞不下；且会丢掉 RT-Thread。

## 9. 本会话踩过的坑（值得记住）

1. **`press_short` 按住 1 帧 ≠ 短按**：`input.c` 的去抖是**电平稳定**判据，`t_edge` 在"发现变化那拍"
   置零 ⇒ 那一拍永远判不过，必须等**下一采样拍**电平仍是新值才认账。
   而且**长按计时的基准是【认账时刻 `down_at`】不是物理按下时刻** —— 所以"物理按住 6.9ms"不能
   拿去和"长按阈值 5ms"比。（我上轮就这么算错了，改成 1 帧反而彻底没反应。）
2. **`PAP_MARK_DEBUG` 必须写精确形式** `<核号/端口/通道号>`，只写数字会让通道映射全错位。
3. **`cdt_ins.exe` 的 TCL 必须纯 ASCII**，中文注释直接中止。
4. **A1 的残留不止 `LANEB_ST`**：它还在 `tb_coremark.v` / `tools/tb_icache_dbg.v` 里留了层级探针
   （`u_core.id_ex_b_mem_write`），退回后 `run_coremark` **编译直接挂**。只 grep `LANEB_ST` 抓不全。
5. **vvp 块缓冲 stdout** ⇒ 重定向到文件时可能跑几小时都看不到一行。`tb_gomoku` 已加每帧 `$fflush`
   + 进度行；其它长仿真也照办。
6. **`.log` 后缀被 gitignore**，抓的日志用 `.txt`。
