## 1. 探针设计

任务 C 要把访存地址计算**从 EX 搬到 ID**，于是 ID 级多出这样一条路径：

```
寄存器堆读 → 前递 mux → 32 位加法器（AGU）→ ID/EX 寄存器
```

探针（`rtl/core/core.v` 的 `AGU_PROBE` 参数，默认 **0**）就插在这里：

```verilog
wire [31:0] agu_rs1 = ex_mem_reg_write ? ex_mem_forward_val : rdata1;  // 真实前递 mux
agu_r <= agu_rs1 + imm;                                                // 真实加法器
```

**[重点] 喂的是真实信号**（`rdata1` 是寄存器堆输出、`ex_mem_forward_val` 是真实前递值、
选择端是真实的 `ex_mem_reg_write`）—— 换成常数或废物逻辑，综合器会整块删掉，
得到假的"零影响"结论（A.1 假 tag 探针踩过这个坑）。
结果寄存器通过 `mem_bus` 的只读 MMIO `0x8000_0028` 回读，所以 PDS 必须保留它。

**默认关**（`AGU_PROBE=0`）：`agu_probe` 恒 0、综合后无任何逻辑，功能与周期逐位不变
（已复测：riscv-tests 6/6 PASS）。

余量从 4.9% 掉到 **1.3%**。

设计上的标准代价就是 ~0.43 ns，可以当作以后插假路径的**经验常数**。

## 4. [重点] 探针量不到的那一半 —— 任务 C 真正的风险

**探针只回答了"ID 级多一个加法器值多少 ns"，它没回答"任务 C 能不能做成"。**
任务 C 的其余改动全都不是"插一条路径"，而是**改协议**：

| 改动 | 风险 |
|---|---|
| **地址-use 冒险** | 地址在 ID 就要 rs1，而上一条指令可能刚写 rs1 → **新的 RAW**。要么把前递搬进 ID（探针含了这一块），要么新增一种停顿 —— **新增停顿会把省下的 load-use 停顿又吃掉一部分** |
| **访存端口整体提前一级** | `mem_addr/mem_we/mem_re/mem_byte_en` 从 EX/MEM 改由 ID/EX 驱动。**AMO 的 4 拍状态机（`amo_hold`）、`mem_ready` 冻结、trap 的 EX/MEM 清除**全都建立在"访存在 MEM 级"这个前提上，要逐条重排 |
| **双发射** | lane A/B 的配对判定、`imem_addr2` 对齐、两条 lane 各自的地址计算 —— 都要跟着动 |
| **store 数据** | 也要在 ID 级就位（rs2 的前递同样提前） |
| **收益本身** | +10.4% 是**上限**（27,181 拍/迭代）。新增的地址-use 停顿、以及前递窗口变化会吃掉一部分 |

**⇒ 时序上：可行（+0.148 ns 仍为正）。工程上：这是一个"改协议"的活，不是"加一条路径"。**

## 5. 建议

**可以开工，但按下面的顺序，并且要接受主频可能要退一档：**

1. **先做冒烟级改造**：只把 **load 的地址**提前到 ID（store 不动、AMO 不动），
   跑 riscv-tests + CoreMark 看周期收益 —— **用最小改动量把 +10.4% 兑现多少**这件事
   先量出来。
2. 拿到收益数字后再决定要不要把 store / AMO / trap 一起搬。
3. 时序上：探针给了 +0.148 ns 的余量，但真实改造还会再吃一些（地址-use 检测、
   lane B 的地址路径）。**如果最终为负，退一档主频是可选代价** —— 但要注意
   `CLAUDE.md` 约定 25/43 记的坑：**放松约束 PDS 会偷懒，未必能换回余量**。

> [!] **判据先行**：第 1 步做完必须先看**周期数**（`+PROF` 的 `region cycles`）
> 与**回归 49/1/0** 两个数字，再往下走。别一次把四件事全改了再跑。

## 6. 局限（如实记录）

- 探针的"地址-use 冒险检测逻辑"没有建模 —— 真实改造在 ID 级还要多一块比较器
  （`rs1 == 上一条的 rd`），以及随之而来的停顿/前递选择。
- 探针只插了一条路径；lane B 的地址计算路径、以及 store 的 rs2 前递路径都**没量**。
- 单次综合、单次 P&R。本机 8-seed，但 P&R 有随机性（`CLAUDE.md` 约定 25）——
  **数值应看作量级，不是精确值**。
