## 8. [!] A4：原来的"闭合式"在双发射下是错的，真数是 12,114 不是 6,912

`+PROF` 新增 5 个**互斥**桶（之和必须 = `tc_noret`，用它自检）：

```
region cycles    : 232,345
region commit    : 214,703
region noretire  :  17,642   ← 正确口径 = cycles − commit（7.59%）
  mc_stall 占    :       0
  load-use 占    :      68   ← 只有 68！停顿拍大多【同时也在退休】
  冲刷当拍占     :     263
  重定向 3 拍内  :   5,197   ← 前端重填（分支代价的一部分）
  [!] 真正无解释  :  12,114   ← A4 的真目标（5.21%）
  其中 IF/ID 空  :     203
```

**根因**：停顿（load-use）发生在 lane A，**同拍更老的指令仍能退休** ⇒ `stall` 拍与
"退休拍"大量重叠，四项相加**会多算**。单发射时那条闭合式精确成立（368 那套数），
双发射下**不成立** ⇒ 我第 1 轮算的"未归类 6,912"是口径错误产生的**假数**。

**⇒ 规矩（已落盘为约定 54）**：双发射下判"有多少拍没干活"用 **`cycles − commit`**。
