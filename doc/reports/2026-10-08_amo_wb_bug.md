# A 扩展的真实缺陷：mc_stall 期间 MEM/WB 会推进

>发现时间：2026-10-08（跑 RT-Thread 硬件原子时暴露）
> 严重程度：**A 扩展的集成方式有错**，单元测试没抓到、riscv-tests 与 CoreMark 也抓不到。

## 现象

把 RT-Thread 切到硬件原子（`-march=rv32ima` + `RT_USING_STDC_ATOMIC`）后：
固件里出现 5 条 `amoadd.w`，仿真在第 1 次 `[ping]` 前**卡死**，
`[pong]` 只出现 1 次（软原子版本是 7 次）。

```
[OK]   [pong] got semaphore, total 1
[FAIL] 一次 [ping] 都没打印 —— 调度器卡在这里了
```

## 根因

`rtl/core/core.v` 里两个级间寄存器的推进条件不同：

| 寄存器 | 推进条件 | 后果 |
|---|---|---|
| `EX/MEM` | `if (!resetn \|\| mc_stall \|\| trap)` → **清空** | AMO 期间保持不动 ✓ |
| `MEM/WB` | `else if (mem_ready)` → **推进** | **AMO 期间照常推进** ✗ |

`amo_unit` 是四拍状态机（READ → HOLD → LATCH → WRITE），`amo_stall` 持续 4 拍。
这 4 拍里 `MEM/WB` 连续推进 4 次，每次都从**被冻结的 EX/MEM** 里取数——
而 EX/MEM 里正是那条 AMO。于是：

```
第 1 拍：MEM/WB 装走 AMO 的标志（mem_wb_is_amo=1）
第 2 拍：MEM/WB 装走同一条 AMO（EX/MEM 没变）
第 3、4 拍：同上
而 amo_wb_data 只在最后一拍有效 —— 此时 MEM/WB 的 rd/wb_sel 早已被覆盖
```

**为什么 mul/div 没这个问题**：它们的结果是**组合**挂在 `alu_result` 上，
`MEM/WB` 推进时直接把那个值锁进去，不需要"等结果"。
而我给AMO 的写回值走的是 `assign wb_data = mem_wb_is_amo ? amo_wb_data : ...`
—— `amo_wb_data` 要等 `amo_unit` 跑完，而那正是 MEM/WB 早就冲掉标志的时候。

## 为什么之前的验证没抓到

| 验证 | 为什么漏 |
|---|---|
| `tb_amo.v` 单元测试 | 只测 `amo_unit`，不经过流水线级间寄存器 |
| riscv-tests 49/1/0 | 测试是 `rv32i_zicsr_zifencei`，**根本不含 AMO 指令** |
| CoreMark 313,886 | 同上，且逐位一致说明**非 AMO 路径没被破坏**（这是好消息） |

也就是说：**我之前所有的"全过"都只在非 AMO 路径上成立**。
A 扩展的 17 项单元测试证明的是模块本身对，不是集成对。

## 修法（两个方向）

### 方向 A：让 MEM/WB 也在 mc_stall 期间冻结（推荐）

把 MEM/WB 的推进条件改成 `else if (mem_ready && !mc_stall)`。
风险：`amo_stall` 期间 WB 级拿到的还是上一条指令的数据，
但那条指令本来就该在原地多停几拍——**这正是 stall 的语义**。
需要确认：现有 `mc_stall` 用户（mul/div）不会因此改变行为
（它们的 WB 值来自组合 `alu_result`，冻结 MEM/WB 只会让写回晚几拍，语义不变）。

### 方向 B：AMO 结果自己锁存，不走 MEM/WB

在 `amo_unit` 内部把 `wb_data` 和 `rd` 在 WRITE 拍一起锁进一个独立寄存器，
WB 级直接用这份私有的写回口，不经过 `mem_wb_*`。
改动更局部，但相当于给 AMO 开一条旁路，复杂度略高。

## 现状

已把 RT-Thread 改回软原子（`git checkout`），回归**4 OK / 0 FAIL**，
固件里 AMO 数量为 0，回到已知良好状态。**缺陷本身尚未修。**

## 教训

> **单元测试通过 ≠ 集成正确。** 这个缺陷在模块级、指令集级、功能级测试里
> 全都是绿的，只有让真实软件（RT-Thread）用硬件原子跑起来才暴露。
>
> 任何"多拍单元"接入流水线时，都要单独问一句：
> **我的结果是在 WB 级组合取的吗？如果是，级间寄存器在 stall 期间会冲掉它吗？**
